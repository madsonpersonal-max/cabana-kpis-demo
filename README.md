# Cabana KPIs — Demonstração visual

Esta versão pública apresenta somente a interface de demonstração do painel gerencial do Cabana Clube.

## Importante
- Todos os números, datas, responsáveis e registros são **fictícios**.
- Não há autenticação real, backend, API, banco de dados ou persistência.
- Nenhuma informação inserida é enviada ou salva.
- Não use esta demonstração para decisões operacionais ou financeiras.
- O sistema funcional e seus dados permanecem em repositório privado.

## Publicação
Para publicar o conteúdo estático pelo GitHub Pages: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**. Depois, aguarde o GitHub concluir a publicação.

## Escopo demonstrativo
Painel gerencial, sete setores, catálogo de 29 indicadores, filtros semanal/mensal/anual, histórico, auditoria ilustrativa e consulta de metas.
